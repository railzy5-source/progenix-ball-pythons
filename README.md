# Progenix Ball Pythons

High-end genetics, detailed breeding tracking, and surplus availability. Manage your collection with precision.

## Development

This project was reorganized to follow standard Vite/React conventions:
- Source code is located in the `src/` directory.
- `App.tsx` and `main.tsx` are the entry points.
- Static assets are in the `public/` directory.
- Root configuration files (`package.json`, `vite.config.ts`, etc.) are at the project root.
